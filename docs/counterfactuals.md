# Counterfactual Analysis

Counterfactual analysis perturbs recorded evidence inputs and re-runs the
deterministic ranking to answer questions such as: what if candidate A had more free
memory, what if a queue were empty, what if transfer cost were removed, what if
reusable state were local, what if a deadline were tighter, what if a node were
unhealthy, or what if policy weights changed.

Counterfactual results are always labelled derived and are never presented as
historical fact. Each result reports the exact changed inputs and the resulting
ranking and decision, and whether the decision changed.
